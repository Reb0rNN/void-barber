# VoidBarber

Адаптивный одностраничный сайт барбершопа по исходникам Figma Make. Проект использует HTML5, CSS3 и нативные JavaScript ES Modules, без сборщика и сторонних frontend-библиотек.

## Структура

```text
VoidBarber/
├── index.html
├── README.md
└── assets/
    ├── css/
    │   ├── tokens.css       # Цвета, шрифт, типографика, интервалы и базовые стили
    │   ├── layout.css       # Секции, сетки, header, контакты и footer
    │   ├── components.css   # Кнопки, карточки, формы, меню и модальное окно
    │   └── responsive.css   # Мобильные и планшетные правила, reduced motion
    ├── fonts/
    │   └── Inter-VariableFont_opsz,wght.woff2
    ├── images/
    │   ├── voidbarber-hero-1621645582931.webp
    │   ├── voidbarber-about-1672257493626.webp
    │   ├── hero-barbershop.webp
    │   ├── about-interior.webp
    │   └── figma-make-resource-83eff80e8dcf50a6dde6890a502f019de03a3524.png
    └── js/
        ├── site-data.js     # Подтверждённые контакты, услуги и локальные изображения
        ├── main.js          # Инициализация и отрисовка бренда и контактов
        ├── navigation.js    # Мобильное меню и управление фокусом
        ├── services.js      # Карточки услуг и цены из site-data.js
        └── booking.js       # Демонстрационная форма записи
```

## Запуск

ES Modules запускайте через локальный HTTP-сервер. Например, из корня проекта:

```powershell
py -m http.server 8000
```

Затем откройте <http://localhost:8000/>. Установка зависимостей и сборка не нужны.

## Данные и функции

- Контакты, адрес, услуги, описания и подтверждённые цены хранятся в `assets/js/site-data.js`.
- Услуги без подтверждённой цены показываются с пометкой «Цена уточняется».
- Неуказанные часы работы, длительность услуг и возрастные ограничения не выводятся.
- Социальные профили VK, Telegram и Instagram не подключены, поскольку их адреса не предоставлены. Используются только подтверждённые способы связи.
- Форма записи проверяет введённые поля и показывает демонстрационное подтверждение. Она не отправляет и не сохраняет персональные данные.
- Адрес сохранён в предоставленном виде. Его географическое соответствие необходимо проверить перед публикацией.
- Фото в Hero и блоке «О нас» — оригинальные локальные ресурсы Figma Make в WebP. Фотографии старого сайта оставлены локально для возможного использования, но в текущих секциях не подменяют изображения макета.

## Соответствие макету и ограничения

Сохранены секции и порядок Figma Make: Header/Navigation, Hero, «О нас», «Услуги и цены», «Контакты», Footer и модальное окно записи. Используются локальный Inter, оригинальные фотографии, SVG-стрелки, цвета и правила адаптивности исходных CSS.

Figma MCP предоставил исходные HTML, CSS и JavaScript Make-файлы. Его screenshot endpoint не поддерживает Make, поэтому сравнить страницу с отдельным рендером Figma не удалось; макет реализован по исходному коду. Ресурс `public/favicon.png` указан в Make-файлах, но Figma MCP не предоставил его содержимое; браузерный запрос к отсутствующему favicon отключён. Неподтверждённые цены, часы, статистика и фиктивные социальные адреса из прототипа не используются. В секции «О нас» убраны неподтверждённые статистические показатели.

Реальная система бронирования и публикация сайта пока не подключены.
